# Google Docs to Confluence HTML Converter

This branch contains the implementation for converting Google Docs documents to Confluence-compatible HTML format.

## Instructions for uploading your Google Docs HTML file:

1. Download your Google Doc as HTML:
   - Open your Google Doc
   - Go to **File → Download → Web Page (.html, zipped)**
   - Extract the HTML file from the zip

2. Upload the HTML file to this branch:
   - You can upload it directly here on GitHub
   - Or place it in the repository root

3. Let me know the filename and I'll convert it to Confluence format!
